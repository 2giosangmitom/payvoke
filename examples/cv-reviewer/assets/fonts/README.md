# Bundled fonts

Unmodified Noto Sans Regular and Bold from the official Noto fonts repository:

- https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
- License: SIL Open Font License 1.1; see `LICENSE` alongside the fonts.

The fonts are bundled with the agent and its Docker image. No font downloads
or system font installation are needed at runtime.
